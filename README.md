# 突破指令

篮球防守持球突破实验用的**进攻人指令卡**。现场把手机交给发指令的人（进攻人 / 背后实验员），防守人不要看屏幕。

- 001–015 三人一组轮换：一人防、一人攻、一人歇
- 防守人的 4 次按 Williams 方顺序
- 大字显示：左顺 / 左交 / 右顺 / 右交
- 可遮住指令、作废按同一条重测、屏幕尽量常亮

## 手机怎么用

1. 用手机打开 GitHub Pages：https://git5018-xb.github.io/breakthrough-cue/
2. 点「从场次 01 开始」
3. 把手机交给进攻人后再点「显示给进攻人」
4. 做完点「完成，下一次」；走步/抢跑点「作废重测」

单页离线副本：[`docs/index.html`](docs/index.html)

## 顺序说明

四种条件：左顺、左交、右顺、右交。  
Williams 四行挂在**防守人**身上，进攻人只执行当前防守人的那一行。
